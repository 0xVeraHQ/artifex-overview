### 1. Install Freighter and fund it (Testnet)

1. Install [Freighter](https://www.freighter.app/) in the browser.
2. Create an account, or import one you can spend on Testnet.
3. In Freighter, set the network to **Testnet**.
4. Copy the public key (it starts with `G`).
5. Fund it with [Friendbot](https://friendbot.stellar.org/).

Confirm the account on [Stellar Expert Testnet](https://stellar.expert/explorer/testnet).

### 2. Open the Try it offer (when Testnet was live)

1. Open the app marketplace and find **Estudio en azul** / **Try it**.
2. Connect Freighter, buy **1** unit, approve in Freighter.
3. Confirm the transaction on Stellar Expert Testnet.

XLM from Friendbot was enough for that path. Other listings used Testnet USDC (Circle issuer `GBBD47IF6LWK7P7MDEVSCWR7DPUWV3NY3DTQEVFL4NAT4AQH3ZLLFLA5`).
