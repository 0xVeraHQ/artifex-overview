# Try it

## Mainnet (live)

A judge can buy one public participation unit on **Stellar mainnet** and see it arrive.

| Field | Value |
| --- | --- |
| Work | **Estudio en azul** (Elena Varga) |
| Offer | **1** · title **Try it** |
| Modality | Participation — future sale |
| Price | **0.1 XLM** per unit |
| Network | **Stellar mainnet (Public)** |
| App | [https://artifex.0xvera.com](https://artifex.0xvera.com) |
| Piece (verify) | [Public verify page](https://artifex.0xvera.com/verify/67b36becdd2b12df0918a9e68cd02b964595b970e0063f53f01066f5fb70fbbe) |
| Seed | `hackathon-scale-15-v6-mainnet` |

### 1. Install Freighter and fund it

1. Install [Freighter](https://www.freighter.app/) in the browser.
2. Create an account, or import one you can spend on mainnet.
3. In Freighter, set the network to **Public**.
4. Fund it with real XLM (fees + 0.1 XLM for this purchase).

Confirm the account on [Stellar Expert](https://stellar.expert/explorer/public).

### 2. Open the Try it offer

1. Open [https://artifex.0xvera.com](https://artifex.0xvera.com).
2. Open [Marketplace](https://artifex.0xvera.com/marketplace) (or the catalog) and find **Estudio en azul** / **Try it**.
3. Connect Freighter from [Connect](https://artifex.0xvera.com/connect) if asked.
4. Buy **1** unit and approve in Freighter.

Other listings use Circle mainnet USDC (issuer `GA5ZSEJYB37JRC5AVCIA5MOP4RHTM335X2KGX3IHOJAPP5RE34K4KZVN`); those need a USDC trustline.

### 3. Check that you received it

Open the transaction on [stellar.expert public](https://stellar.expert/explorer/public) and confirm the units. Catalog: [PIECES.md](PIECES.md).
